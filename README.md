#  Graph Algorithms Visualizer

A Python-based project to visualize and analyze fundamental graph algorithms including **Dijkstra’s Shortest Path**, **Prim’s Algorithm**, and **Kruskal’s Algorithm**.  
This project demonstrates core concepts from **Discrete Mathematics and Graph Theory** with real-time visualization.

---

##  Features

-  **Dijkstra’s Algorithm**
  - Computes shortest path from a source node
-  **Minimum Spanning Tree (MST)**
  - Prim’s Algorithm
  - Kruskal’s Algorithm
-  **Graph Visualization**
  - Displays nodes, edges, and weights
  - Highlights MST edges
-  **Modular Code Structure**
  - Organized into multiple folders for clarity and scalability
-  **Unit Testing**
  - Ensures correctness of implemented algorithms

---

##  Concepts Covered

- Graph Theory
- Weighted Graphs
- Shortest Path Algorithms
- Minimum Spanning Trees
- Greedy Algorithms

---

##  Tech Stack

- **Python 3**
- **NetworkX** – Graph handling
- **Matplotlib** – Visualization
